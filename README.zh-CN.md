# TableBridge：固定版式 PDF 表格转 Excel

这是一个在自己电脑上运行的小工具，用于把相同版式的 PDF 表格合并成 Excel。界面以中文为主，无须购买 API，也不需要把文件发给云端 AI。

## 第一次使用

1. 安装 Python 3.11 或 3.12：https://www.python.org/downloads/ 。Windows 安装时保留 Python Launcher，建议勾选 Add Python to PATH。
2. 将项目完整解压到一个容易找到的目录。
3. Windows 双击 `start-windows.bat`。第一次会安装依赖；安装完成后自动打开浏览器。
4. 保持黑色命令窗口开启。若浏览器未自动打开，访问 `http://127.0.0.1:8765`。
5. 点击“使用示例报价单” → “转换并预览” → “下载 Excel”。

Windows 启动脚本尚未在本次 Linux 开发环境中进行 Windows 实机测试。打不开时，将错误文字复制出来；不要只关闭窗口。

macOS/Linux 用户按英文 README 的三条安装命令运行。

## 正确理解“固定版式”

内置模板只对应 examples 中的模拟报价单。客户文件可以是另一种固定版式，但需要先建立对应模板。

第一版要求：文字能选中、表格有边框线、每页一个表格、第一行列名相同且每页重复表头、无合并单元格。扫描件、无边框表格、手写内容和混合版式不能直接处理。任何一页无法匹配，整批停止，并显示出错文件与页码。

不是把任意 PDF 放进去都能成功。接单前先取得一页样本，确认实际效果再报价。

## 自己动手验收

- `demo-quotation.pdf`：应得到 8 行、2 页；第一个编号仍为 `001`。
- `demo-amount-warning.pdf`：应出现 1 条金额差异提示，源金额 160 保持不变。
- `demo-wrong-layout.pdf`：应明确提示表头不匹配，不能下载一份假装成功的文件。
- 同时选择前两份文件：应得到 10 行、3 页、1 条差异提示。

Excel 的 `Data` 是整理后的数据，`Raw text` 保留提取时的原始文本，`Review` 记录检查提示。交付前对照原 PDF 核对行数、编号、金额、空值和换行内容。

## 调整模板

展开“调整模板”，可以编辑、保存或导入 JSON。详细说明见 [模板说明](docs/TEMPLATES.md)。收到真实样本后再调整，不要凭空猜测列名和区域。

## 发布与使用

GitHub 上发布的是源代码，别人下载后在本机使用。GitHub Pages 不能运行这个 Python 后端。本版不是公开在线 SaaS。

程序仅监听本机地址。不要开放到公网；不要把客户原文件、身份材料、账号凭据放入公开仓库。

这是借助 AI 开发的开源项目，转换时使用确定性规则，不调用 AI。全部示例均为模拟数据，没有虚构客户和收入。
